# Thesis-benchmarks
Graph benchmarks for thesis work

Graphs are divided in three dataset, each dataset has the same specifics. 

Files are .txt extensions, with a first line composed of number of nodes N, minimum clique size K, number of colors C. 
Following that there are N lines, one for each node, that specify what color the node belongs to. 
Finally there is the graph represented through an adjacency matrix. 

# Example

For a graph of 4 nodes, 2 colors, min size 3 the file would look something like:

1 <br />
